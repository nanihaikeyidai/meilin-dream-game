## 一、产品愿景

构建一个**多模板、沉浸式、全感官**的 AI 视觉小说 (AVG/Visual Novel) 平台。

玩家通过文字对话推动剧情，游戏引擎实时渲染：
- ✅ 场景背景图
- ✅ 角色半身立绘（含表情切换）
- ✅ 文字/选项交互
- ✅ **最终目标：语音配音（TTS）+ 语气标签**

支持多套剧情模板自由切换（校园 / 古风 / 都市 / 悬疑 / 科幻）。

### 5.3 表情切换系统

**LLM 协议：**
- 显式标签：`[EXPR: smile]` — 强制切换表情，不依赖文本关键词
- 隐式检测：文本中包含"微笑""脸红"等关键词 → 自动切换对应表情
- 优先级：显式标签 > 隐式关键词

**前端实现：**
```javascript
// 当前已实现
function detectExpression(text) {
  // 先检测显式标签 [EXPR: xxx]
  const explicitMatch = text.match(/\[EXPR:\s*(\w+)\]/);
  if (explicitMatch) return explicitMatch[1];
  // 再检测关键词
  for (const [keyword, exp] of Object.entries(EXPRESSION_KEYWORDS)) {
    if (text.includes(keyword)) return exp;
  }
  return null;
}
```
**状态：** 已接入，立绘素材已齐。

### 5.4 TTS 语音系统

**状态：** 已实现基础链路（`frontend/server_tts.py` + `/proxy/tts` + `[MOOD]`）。

**目标：** 角色对话时自动播放语音，支持语气变化。

**架构：**

```
LLM 输出 → 解析 [TTS] 标签
          ↓
检查 assets/voices/{charId}_{pageIdx}.mp3
          ↓
    存在? → 播放
    不存在? → 调用 TTS 引擎 → 生成 → 缓存 → 播放
```

**标签协议：**
```
林雪 [MOOD: warm]「你来了。」 → 生成时用 warm 参数
[TTS: 音频文本] → 当 TTS 文本和显示文本不同时
```

### 5.5 语气标签系统（迭代 3）

**标签定义：**

| 标签 | 效果（TTS） | 效果（UI） |
|:----:|------------|-----------|
| `[MOOD: warm]` | 语速适中，音调稍高 | 无特殊效果 |
| `[MOOD: sad]` | 语速慢，音调低 | 文字颜色微蓝 |
| `[MOOD: angry]` | 语速快，音量增大 | 立绘→ angry 表情 |
| `[MOOD: happy]` | 语速快，音调高 | 立绘→ happy 表情 |
| `[MOOD: shy]` | 语速慢，声音变小 | 立绘→ blush 表情 |
| `[MOOD: cold]` | 语速平稳，音调低 | 立绘→ cold 表情 |

**LLM 输出示例：**
```
谢云岚 [MOOD: cold]「此事与你无关，不必再问。」
↓ 前端解析：
  角色: 谢云岚 → 立绘 xieyunlan/cold.png
  表情: cold
  TTS: edge-tts voice YunxiNeural, rate=-10%, pitch=-5%
  音频: 播放 / 缓存
```
