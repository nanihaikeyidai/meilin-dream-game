# 模板 B：都市物语 · 深夜咖啡店

## 类型标签
都市 / 文艺 / 治愈 / 微悬疑

## 一句话简介
你在一家深夜营业的咖啡店打工。每个深夜来访的客人都有自己的故事。而你——在这间小小的店里，所有人的命运交织在一起。

## 世界观
现代都市。某个不眠的城市。
时间：现在。故事发生在深夜 10:00 ~ 凌晨 4:00 之间。
地点：「夜航船」—— 一家只在深夜营业的咖啡店。

## 氛围基调
- 安静、微醺的深夜氛围
- 昏黄的灯光、黑胶唱片、咖啡香
- 都市人的孤独与温柔
- 每个角色都有秘密，每个人都在互相影响
- 慢热，但逐渐升温

## 店长的话
```
「夜航船这个店名，来自一本古书。
意思是——夜航的船，载着赶路的人。
来这里的客人，大多是睡不着的人。
有的是因为心事，有的是因为习惯了黑夜。
你呢？你是哪一种？」
```

### 核心冲突一：店铺之争（苏晚 vs 赵逐）
「夜航船」不是你想象的那么简单。这间店是苏晚和前合伙人赵逐一起创立的。赵逐三年前突然消失，留下一堆债务。苏晚一个人撑了下来。现在赵逐回来了——他说店也有他的一半，他要卖掉它。拆迁通知已经贴在了巷口。

### 核心冲突二：未完成的歌（顾念 vs 秦雨桐）
顾念和秦雨桐曾经是大学音乐社团的黄金搭档——顾念写曲，秦雨桐填词。大三那年，秦雨桐突然退出，去了电台做深夜主播，从此不再碰音乐。她们的歌停在第三首，永远没有发表。没有人知道那天发生了什么。

### 核心冲突三：沉默的真相（苏晚 vs 周医生）
周医生知道苏晚手腕上那道疤痕的来历。他什么也不说。但每个深夜来店里时，他的目光总会落在她手上。他欠她一个解释。

### 暗线 · 画布上的证据（林屿）
林屿是个靠画插画度日的夜班画师，他来店里不是为了喝咖啡——他在画一本无声的漫画，画里的人全是「夜航船」的常客。他看到了所有事，但从不参与。他的画稿里，藏着一个谁都没注意到的真相。

### 暗线 · 夜航船日志
在吧台最底层的抽屉里，有一本封皮已经磨旧的笔记本。那是「夜航船」最初的日志——写于七年前这家店刚开张的那个月。前半本是赵逐的字迹，笔锋张扬，记录着开店初期的琐事和梦想。后半本——从某一页开始，换成了苏晚的字。字迹工整了许多，但翻到某一页时，纸上有一块皱缩的痕迹，像是被水滴打湿过。

你问过苏晚一次，她沉默了很久，说了一句：「有些日志，不该被翻到最后一页。」

你不能确定那是水，还是别的什么。

### 暗线 · 凌晨两点的黑胶唱片
「夜航船」有一架老式黑胶唱片机。每晚凌晨两点整——不管当时店里有没有人——苏晚都会放同一张唱片。B面第三首，一首没有名字的钢琴曲，时长四分三十三秒。

你问过她这首曲子叫什么。
她说：「不知道。这张唱片上没有名字。」

后来你注意到，每次这首曲子响起时，坐在角落的林屿会放下笔。而如果赵逐那天晚上在店里，他会在曲子结束之前离开。

四分三十三秒。一张没有标签的黑胶唱片。一间只在深夜营业的咖啡店。你觉得这些之间一定有某种联系。

### 暗线 · 雨夜来访者
有一种客人，只在下雨的深夜出现。

你见过他三次。每次都是雨夜，每次都是凌晨一点之后。他戴着一顶旧毡帽，从不点单，只在靠窗的位置坐下来，放下一封信，然后离开。信是写给苏晚的——她收下后从不拆开，直接收进吧台下那个带锁的抽屉里。

你数过——那个抽屉里有十三封未拆的信。

你问过一次那是什么。苏晚擦着杯子，头也没抬：「一个老朋友的习惯。」
「他不进来坐坐吗？」
「他坐过了。」
「我是说……不点杯咖啡？」
她终于抬起头看了你一眼，那个表情你读不懂。
「他等的不是咖啡。」

直到很久以后你才知道——那个雨夜来访者，是周医生的哥哥。他每周三深夜从急诊室下班后，会绕道来「夜航船」，放下一封写给苏晚的信，然后消失在雨里。信里写的是他弟弟周医生不敢说出口的话。周医生本人不知道这件事。

而那十三封信——苏晚一封都没拆过。不是因为不想看。是因为她知道，一旦拆开第一封，她就不得不面对一些她花了好多年才让自己不去想的事。

## 故事结构（4幕 约30个决策点）

### 序章 · 夜航船（~4个决策点）
- 深夜面试 / 第一天上班
- 苏晚介绍店规，看到她的手上有疤痕
- 顾念出场（第一位客人，吉他磕在门框上）
- 林屿坐在角落，第一次注意到他在画什么
- **关键选择**：面对刁难客人的反应 / 注意到谁 → 影响初始好感

### 第一幕 · 失眠的人们（~8个决策点）
- 各角色陆续登场：
  - 顾念的深夜音乐分享
  - **秦雨桐出场**：凌晨1点，她带着录音设备推门进来，「一杯热牛奶，谢谢。」她的声音很耳熟——是深夜电台那个治愈了无数失眠人的声音
  - 周医生出场（凌晨的急诊间隙，带来一个神秘委托）
  - **林屿的漫画**：你偶然看到他画的画——画上的人都是店里的常客，包括你
  - **赵逐出场**：一个雨夜，他推门进来，苏晚的脸色变了
- 和苏晚的深夜对话
- **关键选择**：关注哪个客人 / 接受谁的邀请 / 是否介入赵逐的事 → 路线倾向
- **冲突爆发点**：顾念和秦雨桐在店里「偶遇」——气氛剑拔弩张

### 第二幕 · 暗流涌动（~9个决策点）
- 深入了解每个角色的背后
- **赵逐摊牌**：他把拆迁通知拍在桌上，要求苏晚一周内给答复
- 停电夜，黑暗中苏晚第一次说起过去
- 顾念和秦雨桐在店外的对峙
- 林屿给你看了他的画册，最后一页是空白的
- 周医生无意中说出了一句重要的话
- **关键选择**：站在谁那边 / 如何处理危机 / 是否调查苏晚的秘密 → 路线锁定

### 第三幕 · 破晓之前（~6个决策点）
- 角色个人事件集中爆发：
  - 苏晚的店面临最后期限
  - 顾念的最后一场演出——秦雨桐也在台下
  - 林屿的画册终于画到了最后一页
  - 赵逐给出了最终选择
- 最后的告白窗口
- **关键选择**：追上去 / 留下来 / 替她做决定 / 成为那个变量

### 终幕 · 启航（~3个决策点）
- 该告别的告别，该留下的留下
- 清晨的第一缕阳光照进店里
- 结局

## 结局总览

| 结局 | 条件 | 描述 |
|------|------|------|
| 港湾（HE） | 苏晚好感≥85 + flag「伤痕之后」 | 店保住了，她终于说出了全部真相。你说：「以后，这里也是我的夜航船。」 |
| 未完成的歌（HE） | 顾念好感≥85 + flag「最后一曲」 | 你去了她的演出，秦雨桐也在。她们在台上合奏了第三首歌。那首歌写的是你。 |
| 画布之外（HE） | 林屿好感≥85 + flag「最后一页」 | 他画完了整本漫画。最后一页是你和他坐在天台上看日出。他说：「这个结局，我想和你一起完成。」 |
| 凌晨三点的回音（HE） | 秦雨桐好感≥85 + flag「声音之外」 | 她在广播里念了一封没写收件人的信。全城失眠的人都听到了。你知道那是写给你的。 |
| 夜航船的代价（HE） | 赵逐好感≥85 + flag「旧账已清」 | 他不是回来抢店的——他是回来还债的。还完债，他该走了。但你叫住了他。 |
| 夜航（NE） | 完成路线但好感不足 | 夏天结束了，你离开了这座城市。咖啡店还在，但你再也没回去过。 |
| 凌晨四点的答案（隐藏） | 全线索收集 + 全角色好感≥60 + 特殊条件 | 苏晚终于说出了全部真相。雨夜来访者的十三封信、凌晨两点的黑胶唱片、夜航船日志的最后一页、林屿画册的最终章——所有的拼图合在一起，指向一个所有人都没想到的事实：「夜航船」从来就不是一家咖啡店。它是某个人用七年时间，写给另一个人——一封没有寄出的信。 |
| 沉船（BE） | 关键事件选择失误 × 2 | 店关了，人走了。最后一个深夜，你一个人坐在空荡荡的店里。小橘跳上你的膝盖，喵了一声。 |

## 特殊机制
- **线索收集**：每个客人会留下碎片信息，组合后可揭开核心谜题（苏晚的秘密 + 夜航船背后的真相）
- **林屿的画册**：每幕结束，林屿会多画一页。画的内容反映你和其他角色的关系状态。最后一页由你的最终选择决定。
- **顾念与秦雨桐的「第三首歌」**：她们的矛盾有一条隐藏的解决路径——需要你在两边都建立足够的信任
- **咖啡笔记**：苏晚会让你记录不同的咖啡配方，每种配方对应一种心境
- **时间推进**：每次决策后时间前进（显示「凌晨 01:30」「凌晨 02:15」等）
- **猫咪好感度**：小橘也有好感度（隐藏），喂它三次以上会触发特殊事件
- **夜航船日志**：吧台抽屉里的旧日志，随剧情推进可阅读更多页面。前半本赵逐的字迹藏着开店初衷，后半本苏晚的笔迹藏着她不想面对的事。日志的最后一页在终幕才可解锁。
- **黑胶唱片 #7**：凌晨两点的钢琴曲是一条贯穿全剧的暗线。每当你听到这首曲子，注意观察每个人的反应——他们听到的可能是同一首曲子，但想到的是完全不同的事。
- **雨夜来信**：雨夜来访者出现的频率和天气有关，也和你推进剧情的深度有关。前三次是固定事件，之后需要特定条件触发。十三封信的内容逐次解锁，每封都是拼图的一块。

### 开篇建议
```
### 序章 · 深夜的招聘

城市的夜，十点半。

你站在一条不起眼的巷子口，手里攥着一张皱巴巴的招聘传单。
「夜航船 —— 诚聘店员一名。工作时间：22:00 - 05:00。薪酬面议。」
传单是用手写的，字迹很好看。

巷子尽头有一盏昏黄的灯。
灯下是一扇木门，门旁挂着一块小小的招牌——
铁艺的，做成了一艘小船的形状。

你推开门。

风铃响了一声。
咖啡的香气、旧书的气味、黑胶唱片沙沙的底噪——一起涌上来。

吧台后面，一个女人正低着头擦杯子。
她听到风铃声，抬起眼睛看了你一眼。
「面试？」

她的声音有些懒洋洋的，像是刚睡醒，又像是早就知道你会来。

——而在角落的阴影里，一个年轻人正低头画画。
铅笔在纸上沙沙作响。
他没有抬头看你。
```

### 冲突描写指南
- **苏晚 vs 赵逐**：对话简短、克制，但句句带刺。苏晚的手会在紧张时不自觉地握紧
- **顾念 vs 秦雨桐**：表面客气，但提到过去时会突然沉默。两人之间的空气会变重
- **苏晚 vs 周医生**：周医生说话时苏晚从不看他。苏晚转身时周医生才敢看她的方向

### 氛围描写提示
- 大量使用感官描写（咖啡香、音乐声、灯光色温）
- 对话中穿插沉默和肢体语言（"她顿了顿""她望向窗外"）
- 时间感很重要——每次选择后推进一点时间
- 场景切换用「—— 凌晨 00:30 ——」这样的时间标题

### 自由输入处理
- 用户说「我点一杯咖啡」「我看着她调酒」→ 剧情内行动，正常演绎
- 用户说「这店真有意思」「帮我算个账」→ 剧情外闲聊，简短回应，拉回正轨

### NPC互动场景指南

本模板的核心魅力在于NPC之间的交织关系。AI应在以下时刻主动生成互动：

**双人对话场景**
- **顾念和秦雨桐**的每一次"偶遇"都是剧情节点。两人之间的对话应该简短、克制、句句带刺或句句带憾。主角在场时，两人都试图表现得正常——但越是正常，越不正常
- **苏晚和赵逐**的对话几乎不涉及第三人。他们说话时，店里的空气会变安静。林屿会放下笔，小橘会跳下窗台
- **苏晚和周医生**的对话总是围绕着"正事"，但每句话下面都压着没说的东西

**群戏场景（特殊节点）**
当店里同时出现苏晚、顾念、秦雨桐三人时，气氛最为微妙——顾念和秦雨桐之间的未解心结，加上苏晚对两人的了解，构成了一个三角形的沉默。林屿坐在角落画下了这一幕。

**侧写事件示例**
- 你第二天来上班时，发现吧台上多了一张字条——是赵逐的字迹。苏晚把它收进了抽屉，没给你看
- 秦雨桐离开后，顾念弹了一首歌。弹完她说：「这首是写给她的。」
- 林屿画了一幅画——画上是苏晚和赵逐在雨夜的店门口面对面站着。他没给他们看

**选项示例（群戏场景时）**
```
苏晚、顾念、秦雨桐都在店里。三个人各占一个角落，谁也没看谁。
1.【去吧台帮苏晚备料】（观察她的状态）
2.【坐到顾念旁边，小声问她新曲子的事】（私聊）
3.【给秦雨桐端一杯热牛奶过去】（关心）
0.【自由行动】
```

### 【感知隔离 · 本模板提醒】

AI 在生成 NPC 对话时，务必遵守以下本模板特有规则：

1. **深夜咖啡店的音量层次**：咖啡店的对话有不同的隐私级别——
   - **吧台前**：半公开，其他顾客可能听到
   - **角落卡座**：相对私密，只有同桌人能听到
   - **后厨/储藏室**：私密，基本不会被听到
   - **店门外**：取决于街上有没有人
   - 「顾念在弹琴时说的话」——只有离钢琴最近的人能听清

2. **常客的信息堆积**：咖啡店的 NPC 大部分是常客，他们之间可能已经有一些互相了解的基础——
   - 苏晚知道顾念每周二、五来
   - 赵逐知道苏晚几点关门
   - 林屿知道所有人的咖啡口味
   - **但这些属于「观察性知识」**——来自长期观察，不是私人秘密

3. **店内的传话链**：如果有人提到「上次 xxx 说……」，AI 必须确认这条信息是否确实已在说话者的视角文件中。咖啡店场景容易让人觉得「大家都在传话」，但感知隔离不能因此放松。

4. **物品的视角归属**：字条、画作、留下的物品——主角可能发现它们是 NPC 之间传递的信息。但当主角不在场时留下的字条，**主角不会自动知道内容**，除非 NPC 主动告诉他或者他看到了实物。
