# 主角创建模板

## 快速创建

```

一句话性格：【  活泼开朗 / 沉默寡言 / 温柔体贴 / 傲娇毒舌 】
核心特征：【  擅长什么 / 害怕什么 / 口头禅 】
```

## 使用说明

1. 将本文件复制为 `[主角名].md`
2. 填写主角信息
3. 游戏开始时由AI读取并加载
