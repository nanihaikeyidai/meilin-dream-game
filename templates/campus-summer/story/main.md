# 模板 A：校园青春 · 夏日的回音

## 类型标签
青春 / 治愈 / 怀旧 / 纯爱

## 一句话简介
高三毕业的暑假，你回到了即将拆迁的母校。在那里，你遇到了同样来告别的她/他。一段关于回忆、告别和重新开始的夏日物语。

## 世界观
现代中国，普通小城市。
时间：六月底，高考结束后。
地点：一所即将拆迁的县城高中。

## 氛围基调
- 温暖中带一丝感伤
- 怀旧的夏日气息：蝉鸣、风扇声、夕阳、旧黑板
- 细碎的回忆片段穿插
- 慢节奏，注重氛围和对话

## 故事结构（3幕 共约25个决策点）

### 序章 · 回音（~4个决策点）
- 回到空无一人的校园
- 在教室里与林雪意外相遇
- 走廊里碰到沈清辞在拍最后的校园照片
- **关键选择**：如何开启对话 → 影响初始好感度与路线倾向

### 第一幕 · 旧时光（~8个决策点）
- 一起在校园里走走，回忆往事
- 各角色陆续登场：
  - 苏云溪在操场老榕树下出现
  - 江晓渔拉着你去社团活动室"抢救物资"
  - 夏知遥在学生会的最后整理中与你偶遇
  - 沈清辞邀请你去看她整理的校园摄影集
- **关键选择**：
  - 留在林雪身边 / 跟苏云溪走 / 去帮江晓渔 / 去学生会帮忙 / 陪沈清辞拍照 / 独自转转
  - → 初步路线倾向，同时可建立多角色基础好感

### 第二幕 · 岔路口（~8个决策点）
- 天台上的秘密（发现林雪藏的旧物盒）
- 关于未来的对话——每个人都要去不同的城市了
- 解锁角色出现条件（满足条件后触发）：
  - 程念慈：琴房的偶然相遇
  - 叶小满：雨天的旧图书馆
- 黄昏时分，关键坦白
- **关键选择**：是否追问她的秘密 / 如何回应她的试探 / 选择相信谁 → 路线锁定

### 终幕 · 回音（~5个决策点）
- 取决于前面选择的路线：
  - **林雪线**：奶茶店告白 / 拆迁前的最后约定
  - **苏云溪线**：旧操场星空下的真心话
  - **沈清辞线**：秘密拍照地点的最后一张合影
  - **江晓渔线**：社团活动室的"最后一次排练"
  - **夏知遥线**：学生会室里她摘下的眼镜
  - **程念慈线**：信与那首没有名字的曲子
  - **叶小满线**：验证最后一个传说，以及拆迁前夜的约定
  - **普通线**：各自离开，留下遗憾
  - **隐藏线**：……

## 特殊机制
- **回忆碎片系统**：在场景中可触发回忆闪回（由AI自动插叙），每次回忆揭示一段过去。不同角色触发的回忆内容不同。
- **信物系统**：特定选择可获得物品（照片、书签、社团徽章、创可贴包装纸等），后期可用于解锁隐藏对话或进入特定角色路线。
- **天气系统**：天气跟随剧情变化（晴→多云→黄昏雨→晴），影响场景氛围。雨天概率触发叶小满线相关事件。
- **解锁角色机制**：程念慈与叶小满需要满足特定条件才会解锁，解锁后在后续流程中作为可互动角色出现，拥有独立的好感度与结局。
- **多角色交织**：初期5位女性角色在序章/第一幕均有出场机会，玩家的选择会影响谁对你更亲近。第二幕前会有一次"路线锁定"选择，确定主要攻略对象。

## AI 叙事指南（本模板专项）

### 开篇建议
```
### 序章 · 空教室

六月的最后一天，你站在学校门口。

铁门半掩着，门卫室已经空了。
公告栏上贴着一张泛白的通知：「本校将于七月十五日起拆除，请各位师生尽快清空个人物品。」
落款是三个月前。
你推开铁门，吱呀一声——这声音你听过三年，从来不知道它这么响。
操场上的草已经长到小腿那么高了。
教学楼在阳光下沉默着，像一头年迈的、温顺的兽。

你的教室在三楼，靠东。
走廊里散落着没带走的海报和试卷。风吹过，卷起一角，又落下。
你走到教室门口——

有人先到了。

一个女孩站在窗边，手里抱着一个落满灰的纸箱。阳光落在她的侧脸上。
她听到脚步声，回过头来。
……

「……咦？」
```

2.【「我还以为只有我会来。」】（略带感慨）
3.【默默点个头，走过去看窗外的操场】（沉默但亲切）
0.【自由行动】—— 或者你也可以自己说点什么
```

3.【就在教室里再待会儿】
0.【自由行动】
```

### 氛围描写提示
- 多用感官细节：蝉鸣声、风的气味、阳光的温度、旧纸张的触感
- 适当使用短句营造节奏感
- 对话间穿插角色的小动作（"她撩了一下耳边的头发"）
- 回忆场景用 *斜体* 或不同的语气区分

### 自由输入处理
- 用户说「我走上前」「我看着她」→ 剧情内行动，正常演绎
- 用户说「今天好热啊」「能不能换个故事」→ 剧情外闲聊，简短回应后拉回：「那我们继续——」+ 当前场景

### NPC互动场景指南

本模板的 NPC 之间有以下关系线，AI 应在适当场景主动生成互动：

**群戏场景（第一幕·旧时光）**
林雪、苏云溪、沈清辞、江晓渔、夏知遥五人在不同时间点穿插出现。当两人以上同时在场时，描写她们之间的互动：
- 林雪和苏云溪是初中同学——见面会聊过去的事，语气比和其他人说话时更放松
- 沈清辞和夏知遥不太熟——同在学生会共事过，但仅限于工作关系
- 江晓渔是所有人的"粘合剂"——她会在气氛尴尬时主动说话

**冲突场景（第二幕·岔路口）**
- 如果玩家同时和多个角色建立了好感，某些角色之间会产生微妙的竞争感——不是恶意的，但体现在对话的细微处
- 夏知遥作为学生副会长，和所有人都保持一定的距离——这是她的性格，不是冷漠

**侧写事件示例**
- 「林雪昨天来找你借书——你没在。她说下次再还你。」（苏云溪转述）
- 沈清辞拍的照片里，有几张拍到了别人——她没删，留在了相册里
- 程念慈在琴房弹的那首曲子，花映月站在门外听了一会儿才走

**选项示例（双人互动时）**
```
林雪和苏云溪正在聊初中时的趣事。你站在一旁。
1.【静静听着，嘴角不自觉笑了】（观察）
2.【「你们说的是哪件事？」】（加入对话）
3.【悄悄走开，让她们聊】（体贴）
0.【自由行动】
```

### 【感知隔离 · 本模板提醒】

AI 在生成 NPC 对话时，务必遵守以下本模板特有规则：

1. **初遇时的信息空白**：游戏开始时，所有 NPC 的视角文件都是空的。这意味着 NPC 对主角只有「脸熟」级别的了解。不要自动假设 NPC 知道主角的任何个人信息——除非在角色卡中写了「这个NPC和主角是老同学」的预设背景。

2. **私密对话标记**：校园模板中，以下场景默认是「私密对话」（仅在场者知晓）：
   - 天台上的对话
   - 放学后空教室里的对话
   - 操场看台（傍晚人少时）
   - 单独在琴房的对话
   - 林雪和苏云溪私下见面时的话题

3. **公开信息**：以下信息在校园环境中默认是「公开/半公开」的，所有同学都可能知道：
   - 谁和谁在交往（传闻）
   - 学生会长的名字
   - 学校要拆迁的消息
   - 文化节的日程
   - 「程念慈钢琴弹得很好」这类众所周知的标签

4. **走廊效应**：校园里「隔墙有耳」。如果两个人在走廊或食堂等人多的地方说话，AI 可以合理假设有路过的NPC听到了一部分——具体听多少由 AI 判断，但至少要写入「xxx路过时隐约听到了」到该 NPC 的视角文件。
