# 主角创建模板

## 快速创建

```
主角名：【  】
性别：【  】
一句话性格：【  冷静理性 / 直觉敏锐 / 大胆行动 / 细腻观察 】
核心特征：【  擅长什么（推理/记忆/沟通/观察）/ 害怕什么 / 口头禅 】
职业/身份：【  调查者身份——记者/侦探/学者/作家/民俗学家/自由调查者 】
```

## 使用说明

1. 将本文件复制为 `[主角名].md`
2. 填写主角信息
3. 游戏开始时由AI读取并加载
