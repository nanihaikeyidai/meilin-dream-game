## 四、推理链设计

### 核心谜题1（破解率约70%即可通关）
夏镜秋到底失踪去了哪里？
- 线索链：E-05 → E-03 → E-04 → E-08
- 真相层级：失踪 → 藏在庄园里 → 藏在镜子的另一侧 → 他从未离开

### 核心谜题2（进入真相线的必要条件）
镜子的秘密是什么？
- 线索链：E-06 → E-09 → E-10 → E-12
- 真相：七面镜子是夏镜秋二十年的研究成果——他找到了一种「镜像纠缠」说，镜子可以记录和反射人的意识

### 核心谜题3（隐藏结局必要条件）
夏镜秋还活着吗？
- 线索链：E-07 → E-11 → E-04+E-12
- 真相：夏镜秋的身体在二十年前就已死亡。但他在镜子中「活」了下来——以镜像意识的形式存在

## 五、推理进度节点

| 进度 | 状态 | 触发方式 |
|------|------|----------|
| 0-20% | 迷雾重重 | 初始状态 |
| 20-40% | 感知到异常 | 第一幕线索收集达到3件 |
| 40-60% | 碎片开始拼接 | 核心谜题1破解一半 |
| 60-80% | 接近真相 | 核心谜题1完成 + 核心谜题2开启 |
| 80-100% | 真相线 | 全核心谜题破解 |
