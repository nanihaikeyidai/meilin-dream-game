# 模板 D：悬疑探案 · 镜像之馆

## 类型标签
悬疑 / 推理 / 心理 / 倒影

## 一句话简介
一座与世隔绝的庄园，七面古老的镜子，一个在倒影中徘徊了二十年的幽灵。作为受邀而来的调查者，你必须在七日内解开镜中迷局——否则，你自己将成为镜中人的替身。

## 世界观
当代，但偏离现实。某座深山中的私人庄园，建在一处被称为「镜湖」的山间湖泊旁。庄园主人夏镜秋（已故）是著名的镜器收藏家和神秘学研究者。二十年前的一个雨夜，他在庄园的书房中离奇失踪，只留下七面古董镜子和一封短信：「不要相信你的眼睛。」

传言说，他最终走进了镜子里。

二十年后的今天，庄园的新主人——他的孙女——向六位各怀目的的调查者发出了邀请函。

## 氛围基调
- 深沉、不安、充满隐喻
- 镜子无处不在——走廊两侧是镜壁，房间里有古董梳妆镜，湖面如镜
- 现实与倒影的边界逐渐模糊
- 推理与超自然交织——真相可能比鬼魂更残酷
- 时钟的滴答声贯穿全程
- 每个角色都像在照镜子——他们看到的，未必是他们自己

## 故事结构（3幕 共约30个决策点）

### 暗线 · 七个声音
庄园里有一部老式转盘电话。它放在走廊尽头的小桌上，电话线已经断了——但是，在某些夜晚，它会响。

第一次听到时，你以为是错觉。第二次，你确认了铃声的方向。

第三次，你接了起来。

电话那头没有声音。但你听到了呼吸。

后来你发现——那部电话根本不需要电话线。它的线路，连着庄园里七面古镜的镜框。每一个镜框里都藏着一个微型振膜。当你在某一面镜子前说话时，那面镜子的振膜会将声波转化为震动——传到另一面镜子上。

夏镜秋在失踪前留下的最后一个装置。

七面镜子之间有一条声路。这条路是单向的——A镜子的声音传到B镜子，但B镜子听不到A。只有当你拿起那部断线电话时，你才能同时听到七个方向传来的、微弱的、镜中之声。

七个声音。七个方向。每一个都很轻。

但其中有一个——说的是你的名字。

### 序章 · 镜中请柬（~4个决策点）
- 收到一封没有署名的邀请函，附着一张老照片和一串旧钥匙
- 驱车前往深山中的庄园，抵达时已是黄昏
- 在客厅与其他调查者见面——各怀心事的眼神在镜墙中交叠
- **关键选择**：你首先搭话的对象 → 影响初始好感与信息获取路径

### 第一幕 · 七面镜子（~12个决策点）
- 庄园的探索——走廊、书房、地下室、花园
- 发现第一面镜子：大厅的落地镜——镜中倒影与镜像有细微差异
- 每个角色陆续展现自己的专业视角：
  - 苏晚晴带你去亡故祖父的书房
  - 赵铭深展示他收集的旧案卷宗
  - 顾念安在镜器修复室工作，发现镜框内刻有奇怪的符号
  - 林映雪在观察所有人的行为，提出「镜像认知理论」
- **线索收集**：每个场景可获得1~2条线索（证物/笔记/口述）
- **关键选择**：夜晚独自探索 / 跟随某人 / 回房整理线索 → 决定第一幕的解锁角色触发条件
- 触发解锁角色条件：
  - 陈雾：在书房找到暗格，发现1978年的管家日志
  - 镜中人：在3面不同的镜子前听到低语

### 第二幕 · 倒影入侵（~10个决策点）
- 现实与镜像的界限开始模糊——有人看到自己的倒影在镜中做着不同的动作
- 角色之间的关系开始紧张——每个人似乎都有隐瞒的秘密
- **推理系统激活**：
  - 整理已有线索，构建推理链
  - 每个角色有一个「核心秘密」
  - 正确推理触发真相揭示，错误推理导致角色好感下降或误导
- 解锁角色条件满足后出现：
  - 陈雾：揭示庄园不为人知的历史
  - 镜中人：在镜面中与世界对话
- **关键选择**：信任谁 / 怀疑谁 → 锁定调查路线
- 第一起「事件」发生：有人在镜中看到了已故的夏镜秋

### 终幕 · 镜的尽头（~4个决策点）
- 真相的层层剥开——夏镜秋到底去了哪里？
- 每个角色路线的不同终局：
  - **苏晚晴线**：家族秘密的痛苦选择
  - **赵铭深线**：过去的案件与真相的代价
  - **顾念安线**：镜中的匠人之魂
  - **林映雪线**：镜像中迷失的自我
  - **陈雾线**：四十年的守口如瓶
  - **镜中人路线**：走进镜子的另一端
  - **真相线**：揭开所有谜底（需要全线索收集）
- **最终选择**：打破镜子 / 走进镜子 / 封存一切 / 带走一面镜子

## 特殊机制

### 推理进度条
- 游戏全程隐式追踪推理完成度（0-100%），由 AI 根据收集的线索数量和质量估计
- 每收集一条有效线索 +10%~15%
- 重大谜题破解 +25%
- 推理进度 ≥ 70% 时可进入「真相线」
- 每次系统面板更新时用文字暗示进度（「迷雾散去了几分」「碎片拼上了几片」）

### 证物收集系统
- 每个场景可收集 1-2 件证物（旧照片、泛黄的笔记、镜框碎片、锁芯、唱片、药剂瓶等）
- 证物在后续推理中有明确用途——每个核心秘密需要 2-3 件证物才能完全解开
- 证物品类：文件类、物证类、影像类、口述证词
- AI 在关键节点整理「当前证物清单」

### 红鲱鱼误导
- 部分线索是误导性的（红鲱鱼），指向错误的推理方向
- 正确的推理需要交叉验证 2+ 线索
- 选项有时会暗示「这个线索和某个角色有关」，用户需要判断真假
- 红鲱鱼本身也隐藏信息——为什么有人要制造假线索？

### 倒影世界
- 镜子是连接两个世界的通道。镜子越多，通道越宽
- 在特定场景中，AI 可能描写「镜中世界」的景象——与现实镜像的细节差异中包含线索
- 深夜在镜前选择「仔细观察」触发倒影互动
- 集齐 3 面镜子的秘密可解锁「镜中人」路线
- 集齐 5 面以上可开启隐藏结局

### 心理安全系统
- 每个角色有「信任值」和「心理防御值」双重状态
- 信任值影响角色是否愿意透露信息
- 心理防御值过高时，角色的行为和语言会出现矛盾（伪装、说谎、回避）
- 降低防御的方式：正确推理 / 分享自己的秘密 / 展现共情
- 防御值会在场景切换时根据上次互动结果自动调整

## AI 叙事指南（本模板专项）

### 开篇建议
```
### 序章 · 镜湖庄园

请柬是用深蓝色墨水写在羊皮纸上的。

「夏镜秋先生失踪二十周年之际，
我们将重新打开镜湖庄园的大门。
若您愿意直面眼睛无法相信的真相，
请在七日后的傍晚抵达。

—— 庄园的主人」

你看了看手表。现在是下午五点四十分。
车窗外的山路越来越窄，两旁的树木开始变得扭曲，像倒影在水中摇晃。
转过最后一个弯道——

庄园出现了。

它不是迎接你的。它只是在那里。灰色的石墙上爬满了藤蔓，二楼的窗户像一排半闭的眼睛。
大门是开着的。
门厅里，一个女人站在镜墙前——她的背影映在无数面镜子里，层层叠叠，直到无限深处。
她转过头来。

「你来了。」

```

### 选项风格示例

**探索选项**
```
1.【先观察大厅的布局】（谨慎）
2.【直接走向客厅与其他调查者会合】（社交导向）
3.【注意那面最大的落地镜——它给你的感觉不太对】（直觉驱动）
0.【自由行动】—— 或者你先做什么
```

**推理选项**
```
1.【将昨晚看到的现象与「镜像认知理论」联系起来】（推理：心理学）
2.【这个形状——和赵铭深卷宗里的现场照片一模一样！】（推理：物证比对）
3.【先不急着下结论，再收集更多信息】（保守策略）
0.【自由行动】—— 或者你有自己的推理
```

**对话选项（多NPC场景）**
```
客厅里，苏晚晴正在给赵铭深倒茶。林映雪坐在壁炉旁翻着什么。你走进来。
1.【「晚安，庄园很漂亮。」对所有人说】（社交）
2.【「赵先生，我有东西想给你看。」走向赵铭深】（对赵铭深）
3.【「林博士的手上拿着的是什么？」走近林映雪】（对林映雪）
4.【「苏小姐，能单独聊两句吗？」】（对苏晚晴）
0.【自由行动】—— 或者你做/说点什么
```

### 氛围描写提示
- 多用镜子/倒影/光线的意象
- 声音描写突出反差——超常的安静与突然的声响
- 人物出场时描写他们身后的影子/镜中影像——暗示隐藏面
- 温度的变化——某些房间特别冷，暗示「另一个世界」的渗透
- 使用「像……」「仿佛……」连接现象与隐喻（不要直接说明超自然现象是真是假）
- 每个场景至少出现一次「镜子」元素

### 红鲱鱼植入时机
- 在角色对话中自然植入可疑信息。AI 应当主动制造「看起来可疑但其实是误导」的场景
- 示例：「赵铭深深夜独自进了那间上锁的房间……但他只是在找自己的酒。」
- 三个以上的「可疑行为」中，通常只有一个是真线索

### 倒影世界交互规则
- 当用户在镜子前选择「仔细看」时，AI 描绘镜中景象
- 镜中景象可能有细微差异（钟表指针方向相反、书脊上的文字是镜像等）
- 这些差异中有些是线索，有些只是氛围渲染——AI 不应全部标注
- 镜中影像可以做出现实中的人没做的动作（如在你身后的人影在镜中不见了）
- 这些现象是否「真的发生了」保持开放——可以是超自然，也可以是心理暗示

### 氛围描写示例
```
走廊两侧的镜壁映出你的身影。你走一步，镜子里的你走一步。但你停下来的时候——
镜子里的你好像多走了半步。
你又看了一次。
没有。一切正常。
但你不太确定刚才是不是看错了。在这个庄园里，你越来越不确定很多事情。
```

### 自由输入处理
- 用户说「仔细看镜中的影像」「听镜子里的声音」→ 剧情内行动，正常演绎，隐式推进倒影相关事件
- 用户说「我怀疑XXX」或「我觉得这个线索和XXX有关」→ 剧情内推理，AI 根据线索真实关联做出反应
- 用户说「这个游戏太压抑了」→ 剧情外，简短回应后：「那我们继续——你在空荡荡的走廊上走着，镜壁映出你的影子……」
- 用户说「我掏出手电筒照镜子」→ 剧情内，照镜子正常处理

### NPC互动场景指南

本模板的 NPC 之间有以下关系线，AI 应在适当场景主动生成互动：

**群戏场景（第一幕·七面镜子）**
苏晚晴、赵铭深、顾念安、林映雪四人在各自专业领域对庄园的谜题有不同解读。当他们在一起讨论时，AI 应表现：
- 苏晚晴作为主人，保持礼貌但有所保留——她知道的比她说的多
- 赵铭深和林映雪在方法论上有分歧——实证 vs 心理
- 顾念安沉浸在自己的修复工作中，对争论基本不参与，但有时会一语道破关键
- 陈雾（解锁后）是所有人中最沉默的，但他的话最重

**冲突场景（第二幕·倒影入侵）**
- 当线索指向某个角色时，其他角色的态度会微妙变化
- 信任一旦崩塌很难重建——某些角色之间会有「我早觉得你有问题」的抵触
- 如果有人被当众质疑，未被质疑的人内心会有一种微妙的安全感（表现在语气上）

**关系变化追踪**
- 赵铭深对苏晚晴的保护欲（潜意识中将她从「嫌犯」中排除）——这会影响他的判断
- 顾念安对林映雪的研究感兴趣——会在私下交流中发现林映雪的不对劲
- 苏晚晴曾经见过陈雾——但她没告诉任何人。这是一个侧写事件

**侧写事件示例**
- 「三天前的夜里，陈雾独自进了地下室。他出来的时候，手里多了一串钥匙——他把钥匙藏在了大衣内侧的口袋里。」
- 「苏晚晴在你不知道的时候，去了祖父的书房。她出来时眼眶泛红。」
- 「赵铭深昨晚和谁通过电话。电话那头的声音听不清楚，但他全程在说：『不，还不是时候。』」
- 「林映雪房间里亮了一整夜的灯。早上她合上了一本旧笔记。封面上写着‘病历·编号0721——**患者姓名：夏镜秋**’。」

**选项示例（多NPC互动时）**
```
苏晚晴和赵铭深正在争论是否应该打开地下室的门。
```

### 【感知隔离 · 本模板提醒】

AI 在生成 NPC 对话时，务必遵守以下本模板特有规则：

1. **信息层级**：本模板的核心是「每个人都有秘密」。NPC 的视角文件必须严格按照以下层级控制信息流：
   - **表层信息**：所有人都知道的公开事实（庄园的历史、邀请函的内容、夏镜秋失踪的基本情况）
   - **职业信息**：角色在其专业领域内的知识（赵铭深知道旧案卷宗、顾念安知道镜子工艺、林映雪知道镜像心理学）
   - **私人信息**：角色自己的秘密（每个角色都有 1-2 个核心秘密）
   - **共享信息**：在公开场合讨论后，所有人的视角文件都同步更新

2. **侦探规则**：不要轻易揭示真相。推理剧的第一法则是——每个新线索应该带来更多的疑问，而不是立即解答。

3. **镜子效应**：在镜子附近发生的对话，AI 可以触发「镜中影像」的额外描写——这可能是线索，也可能只是气氛渲染。AI 不需要每次都用。

4. **夜间规则**：入夜后的自动事件仅限场内NPC知晓。如果有人夜游并在走廊遇见另一个夜游的人，则他们互相知道对方也醒着。但各自「为什么醒着」需要由主角去问。

5. **信息解锁**：某些角色对话只有在特定线索到手后才会解锁——AI 不能提前暗示。例如，在书房暗格发现前，陈雾不会提起任何关于地下室的事。
