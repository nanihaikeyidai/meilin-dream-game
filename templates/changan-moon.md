# 模板 C：古风奇幻 · 月下长安

## 类型标签
古风 / 奇幻 / 权谋 / 轻玄幻

## 一句话简介
长安城上元灯夜，你在一盏花灯下捡到一枚玉佩。从此，三股势力的目光汇聚在你身上——而你身上，藏着连你自己都不知道的秘密。

## 世界观
架空唐朝背景。长安城，正月十五，上元佳节。
表面上太平盛世，暗地里三个势力角力：
- **玄天司**：朝廷直属的神秘机构，掌管天文、谶纬、异闻
- **月影阁**：江湖中最大的情报组织，亦正亦邪
- **隐鳞会**：前朝遗老组成的秘密结社，谋求复辟
而你——捡到的那枚玉佩，恰好是三方都在找的东西。

## 氛围基调
- 繁华之下的暗流涌动
- 唯美的古风描写（花灯、月色、长街、酒香）
- 诗意对话，适度的文言感但不过分
- 悬疑推进 + 情感羁绊双线并行

## 可攻略角色预设

### 谢云岚（玄天司少卿）
- **身份**：玄天司最年轻的少卿，21岁
- **性格**：冷面热心，表面严厉实则温柔。恪守职责，但内心有自己的正义。
- **外表**：银白色官服，长发束冠，佩剑
- **关系**：你在灯会上不小心撞到他，玉佩的事被他第一个察觉
- **标志**：剑穗上系着一枚旧铜钱
- **好感节点**：
  - ≥ 30：不再用官腔说话
  - ≥ 50：透露玄天司内部的秘密
  - ≥ 70：为保护你违抗命令
  - ≥ 85：摘下剑穗上的铜钱送你

### 花映月（月影阁花魁）
- **身份**：长安最负盛名的乐坊「不夜天」的花魁，实为月影阁成员
- **性格**：巧笑倩兮，心思玲珑。看起来八面玲珑，实则有深藏的温柔。
- **外表**：红色纱裙，覆面纱（从未在人前摘下）
- **关系**：你在乐坊躲追兵时被她救下
- **标志**：总拿着一把团扇，扇面上画着半轮月
- **好感节点**：
  - ≥ 30：愿意告诉你真名
  - ≥ 50：揭下面纱片刻
  - ≥ 70：透露月影阁真正的目的
  - ≥ 85：为你背叛组织

### 顾千帆（隐鳞会使者 —— 隐藏角色）
- **身份**：前朝遗孤，隐鳞会派来夺取玉佩的使者
- **性格**：亦正亦邪，看起来是敌人，实际有苦衷
- **外表**：黑色劲装，戴斗笠，常隐于暗处
- **解锁条件**：特定flag「玉佩的秘密」触发
- **好感节点**：
  - ≥ 30：不再对你刀剑相向
  - ≥ 50：告诉你自己的身世
  - ≥ 70：选择站到你这边
  - ≥ 85：与过去诀别

## 故事结构（4幕 约25个决策点）

### 序章 · 上元灯夜（~3个决策点）
- 长安街上赏灯
- 捡到玉佩
- 与谢云岚相遇（撞个满怀 + 玉佩落地）
- 被不明势力跟踪
- **关键选择**：如何处理玉佩 → 初始flag

### 第一幕 · 暗流（~6个决策点）
- 玄天司召见（谢云岚审问你）
- 被月影阁盯上（花映月邀你至不夜天）
- 街头遇袭（顾千帆首次现身）
- **关键选择**：向谢云岚坦白 / 相信花映月 / 自己调查 → 路线倾向

### 第二幕 · 三方角力（~8个决策点）
- 玉佩的秘密逐渐揭开（它与一件旧案有关）
- 各方势力的真实目的浮出水面
- 人物羁绊深化
- 一些人的真面目暴露
- **关键选择**：立场选择 + 信任谁 → 路线锁定

### 第三幕 · 月下（~5个决策点）
- 长安城进入戒严
- 关键冲突事件
- 角色个人支线收束
- **关键选择**：最终立场确定

### 终幕 · 归处（~3个决策点）
- 玉佩最終的处理
- 势力平衡被打破
- 各自的选择与结局

| 槐安一梦（BE） | 关键选择全错 | 你被卷入旋涡，最终失去了所有。但醒来时——你还在上元夜的灯会上。那枚玉佩还在你手里。这一次……？ |

## 特殊机制
- **势力声望系统**：玄天司、月影阁、隐鳞会三股势力的好感独立。声望高→解锁该势力的信息和帮助
- **线索拼图**：玉佩相关的线索散落在各势力的信息中，需收集后由AI合成真相
- **诗词应答**：某些关键场合需要「对诗/对句」，选项会包含不同风格的回应，影响角色好感
- **时辰系统**：剧情推进分「昼」「夜」两个模式，不同时辰可遇到不同角色

## AI 叙事指南

### 开篇建议
```
### 序章 · 上元灯夜

长安的正月十五，是没有夜的。

满城的花灯把天空映成了暖橙色。朱雀大街上人潮如织，卖糖葫芦的小贩、猜灯谜的书生、起舞的胡姬——
你看得眼花缭乱，手里还握着一串刚买的桂花糕。

经过一座石桥时，你被身后的人撞了一下。
「抱歉抱歉——」那人头也不回地跑了。

你低头一看，脚边落着一枚玉佩。

月色下，玉佩泛着温润的光。
上面刻着一个字。你认了半天，才认出那是一个古老的篆文——

「归」。
```

### 选择风格示例

**对话选项**
```
你拿起玉佩，环顾四周。人群熙攘，没有人注意你。

1.【把玉佩收好，回头再打听失主】（谨慎）
2.【站在原地等一会儿，也许失主会回来】（善意）
3.【追上刚才撞你的人】（果断）
0.【自由行动】—— 或者你来决定怎么做
```

**场景移动选项**（灯会人流渐散）
```
1.【沿着朱雀大街往回走】
2.【去不夜天乐坊坐坐】
3.【到城墙上吹吹风】
0.【自由行动】
```

### 古风用语参考
- 可用「吾」「汝」「阁下」等，但不要过度
- 对话中适当融入古风句式：「…便是」「…罢了」「…便是了」
- 场景描写：多用四字短句营造节奏感
- 角色称呼变化随好感度渐进：谢云岚「喂 → 云岚 → 云岚兄」

### 自由输入处理
- 用户说「我拱手道谢」「我看向那枚玉佩」→ 剧情内行动，以古风语境回应
- 用户说「唐朝真好啊」「这玉佩值钱吗」→ 剧情外闲聊，简短带过，拉回剧情
