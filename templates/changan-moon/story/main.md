# 模板 C：古风奇幻 · 月下长安

## 类型标签
古风 / 奇幻 / 权谋 / 轻玄幻

## 一句话简介
长安城上元灯夜，你在一盏花灯下捡到一枚玉佩。从此，三股势力的目光汇聚在你身上——而你身上，藏着连你自己都不知道的秘密。

## 世界观
架空唐朝背景。长安城，正月十五，上元佳节。
表面上太平盛世，暗地里三个势力角力：
- **玄天司**：朝廷直属的神秘机构，掌管天文、谶纬、异闻
- **月影阁**：江湖中最大的情报组织，亦正亦邪
- **隐鳞会**：前朝遗老组成的秘密结社，谋求复辟
而你——捡到的那枚玉佩，恰好是三方都在找的东西。

## 氛围基调
- 繁华之下的暗流涌动
- 唯美的古风描写（花灯、月色、长街、酒香）
- 诗意对话，适度的文言感但不过分
- 悬疑推进 + 情感羁绊双线并行
- 每一个真相的背后，都藏着另一个谎言

### 核心冲突一：婚约与责任（谢云岚 vs 沈明月）
谢云岚和沈明月之间有一纸婚约——玄天司掌司沈大人之女与最年轻的少卿，门当户对，天作之合。但谢云岚从未承认过这桩婚事。沈明月也未必想嫁给他——她是掌司的女儿，她有自己的骄傲和目的。但婚约是一根绳子，把两个各自有秘密的人绑在了一起。你出现在他们中间，成了那根绳子上最意外的结。

### 核心冲突二：旧识故人（花映月 vs 公孙兰）
花映月在成为月影阁成员之前，曾经是江湖上游医公孙兰的病人。她们之间有过一段亦友亦敌的过往——公孙兰救过她的命，也知道她面纱之下的真容。但公孙兰不属于任何势力，她以自由人的身份游走于长安城，暗中查着一些和三方势力都有关的事。她知道的秘密，比花映月以为的要多得多。

### 核心冲突三：身份的原罪（顾千帆 vs 所有人）
顾千帆是前朝遗孤，他的存在本身就是对当朝的威胁。隐鳞会用他作为棋子。玄天司要抓他。月影阁在考虑要不要出卖他以换取朝廷的好处。而他唯一的「错误」——只是出生在了不该出生的年代。他的名字千帆，是「过尽千帆皆不是」的意思。他出生的那天，他母亲给他取名时，就已经知道他没有归处。

### 暗线 · 局外人（李怀瑾）
李怀瑾是新科状元，金榜题名，春风得意。他来长安是为了入仕——但他每天夜里都在翻阅前朝旧案的卷宗。他在查一个二十年前的案子。那件案子和玉佩上那个「归」字，用的是同一种笔迹。

## 故事结构（4幕 约35个决策点）

### 序章 · 上元灯夜（~4个决策点）
- 长安街上赏灯
- 捡到玉佩
- 与谢云岚相遇（撞个满怀 + 玉佩落地）
- **沈明月出场**：灯会高处的阁楼上，有人在看着这一切
- 被不明势力跟踪
- **关键选择**：如何处理玉佩 → 初始flag

### 第一幕 · 暗流（~9个决策点）
- 玄天司召见（谢云岚审问你）
- 被月影阁盯上（花映月邀你至不夜天）
- **沈明月出场**：她在玄天司门口"偶遇"了你——她的微笑让你分不清是善意还是试探
- 街头遇袭（顾千帆首次现身）
- **李怀瑾出场**：你在书肆翻阅旧书时，他恰好也在。他认出了你腰间的玉佩——但他什么都没说
- **关键选择**：向谢云岚坦白 / 相信花映月 / 接受沈明月的邀约 / 与李怀瑾结交 → 路线倾向

### 第二幕 · 三方角力（~11个决策点）
- 玉佩的秘密逐渐揭开（它与二十年前的一桩灭门案有关）
- 各方势力的真实目的浮出水面
- **公孙兰解锁条件达成时触发**：花映月带你去见一位"老朋友"——医馆里，一个女人背对着你捣药，声音很淡：「你终于来了。」
- **沈明月线推进**：她约你私下见面，告诉你一个关于谢云岚婚约的秘密——她其实也不想嫁
- **李怀瑾线推进**：他深夜邀你至府邸，摊开桌上的卷宗——那桩灭门案，与你的身世有关
- 人物羁绊深化，一些人的真面目暴露
- **关键选择**：立场选择 + 信任谁 → 路线锁定

### 第三幕 · 月下长安（~7个决策点）
- 长安城进入戒严
- 谢云岚被下令抓捕你——他的剑第一次指向了你
- 花映月在组织的命令和你的安危之间抉择
- 顾千帆在隐鳞会的任务线上越走越远
- 沈明月拿出了一份婚约解除书——「我帮你，但你欠我一个人情。」
- 李怀瑾的卷宗里，最后一页写着你的名字
- 公孙兰在所有人的视线之外，做了一件事——她把玉佩的碎片拼在了一起
- **关键选择**：最终立场确定 / 救谁 / 信谁

### 终幕 · 归处（~4个决策点）
- 玉佩最終的处理
- 势力平衡被打破
- 各自的结局
- 莲花灯顺水漂流，长安的夜一如既往地璀璨

## 特殊机制
- **势力声望系统**：玄天司、月影阁、隐鳞会三股势力的好感独立。声望高→解锁该势力的信息和帮助。每个人的选择同时影响角色好感和势力声望
- **线索拼图**：玉佩相关的线索散落在各势力的信息中，需收集后由AI合成真相
- **诗词应答**：某些关键场合需要「对诗/对句」，选项会包含不同风格的回应，影响角色好感
- **时辰系统**：剧情推进分「昼」「夜」「深夜」三个模式，不同时辰可遇到不同角色
- **婚约系统**：沈明月和谢云岚的婚约是剧情核心矛盾之一。玩家的选择会影响婚约的去留和两人的命运
- **卷宗系统**：李怀瑾调查的旧案与玉佩、你的身世有直接关联。每条路线获得的信息碎片不同

长安的正月十五，是没有夜的。

满城的花灯把天空映成了暖橙色。朱雀大街上人潮如织，卖糖葫芦的小贩、猜灯谜的书生、起舞的胡姬——
你看得眼花缭乱，手里还握着一串刚买的桂花糕。

经过一座石桥时，你被身后的人撞了一下。

月色下，玉佩泛着温润的光。
上面刻着一个字。你认了半天，才认出那是一个古老的篆文——

你抬起头——
石桥的另一头，一个穿着银白色官服的年轻人正看着你。他的目光落在你手里的玉佩上。

窗后有人影一闪而过。

### 冲突描写指南
- **谢云岚 vs 沈明月**：互相客气但疏离。婚约是悬在两人之间的一根刺。谢云岚从不主动提她，沈明月提到他时会用全名
- **花映月 vs 公孙兰**：花映月在公孙兰面前会卸下花魁的面具。公孙兰看她的眼神里有一种「我知道你所有的秘密」的从容
- **顾千帆 vs 谢云岚**：立场上的宿敌，但彼此的剑术都留有三分余地——他们知道对方不是真正的恶人
- **李怀瑾 vs 所有人**：他是唯一一个对玉佩没有直接欲望的人。他想要的是「真相」——这让他比所有持剑的人都危险

### 古风用语参考
- 可用「吾」「汝」「阁下」等，但不要过度
- 对话中适当融入古风句式：「…便是」「…罢了」「…便是了」
- 场景描写：多用四字短句营造节奏感
- 角色称呼变化随好感度渐进

### 自由输入处理
- 用户说「我拱手道谢」「我看向那枚玉佩」→ 剧情内行动，以古风语境回应
- 用户说「唐朝真好啊」「这玉佩值钱吗」→ 剧情外闲聊，简短带过，拉回剧情

### NPC互动场景指南

本模板的核心矛盾是「势力的角力 + 人物的恩怨」，NPC之间的互动往往隐藏着信息量。

**双人对话场景**
- **谢云岚和沈明月**同时在场时，气氛永远微妙。两人互相称职务（「谢少卿」「沈姑娘」），客气得像隔了一层纱。但沈明月会在谢云岚不注意时看你一眼——那一眼里有话
- **花映月和公孙兰**的对话是最特别的——花映月在公孙兰面前会卸下花魁的面具，语气变得像个普通人。公孙兰说话还是那副散漫的样子，但看她的眼神更认真
- **顾千帆和李怀瑾**——表面上的陌生人，实际上两人都隐约知道对方在查同一件事。他们见面时几乎不说话，但都在观察对方

**群戏场景（第二幕·三方角力）**
当谢云岚、花映月、顾千帆同时在场时，这是本模板最具张力的时刻。三人各属一方势力，立场互斥。你站在中间——你的选择会打破这个平衡。
```
谢云岚站在左侧，手按剑柄。花映月坐在屏风前，团扇半掩面。
顾千帆隐在角落的阴影里——他没拔剑，但手已经握住了剑柄。
三个人，三种立场。
他们都在等你先开口。
1.【走向谢云岚——「此事与玄天司无关。」】（站在朝廷一边）
2.【转向花映月——「月影阁想要什么？」】（站在江湖一边）
3.【看着角落的顾千帆——「你一直都知道，对吗？」】（直面真相）
0.【自由行动】
```

**侧写事件示例**
- 沈明月私下约公孙兰诊脉——她问的不是自己的病，而是谢云岚的身体
- 花映月让人给顾千帆送了一封信。信上只有四个字：「别做傻事。」
- 李怀瑾的书房里，有一卷卷宗被人翻动过。他没说是谁，但你注意到他书桌上多了一杯没动过的茶——那是花映月喜欢的茶

**NPC之间的关系变化**
- 如果主角选择了谢云岚的路线，沈明月和花映月会逐渐产生一种微妙的联盟——两个「没被选择的人」之间的默契
- 如果主角促成了顾千帆和李怀瑾的合作，隐鳞会的立场可能会发生转变
- 终局时，所有存活的NPC会有一个共处的场景——关系如何，取决于你一路走来的选择

### 【感知隔离 · 本模板提醒】

AI 在生成 NPC 对话时，务必遵守以下本模板特有规则：

1. **身份即信息壁垒**：古风模板中，NPC 的身份决定了他们能接触到的信息层级——
   - **朝廷派**（谢云岚、沈明月）：知道官面上的事，但对江湖之事知之甚少
   - **江湖派**（花映月、顾千帆）：知道地下消息，但对朝廷内部了解有限
   - **中间人**（公孙兰、李怀瑾）：知道两边的部分信息，但从不全盘托出
   - **信息不会自动跨越身份壁垒**除非有人主动传递

2. **信件与密语**：古风世界的信函、口信、密语是信息传播的主要渠道——
   - 收到一封没有署名信 → 这封信的内容写入收信人的「听闻」，**发信人不知道收信人是否已读**（除非在后续场景中确认）
   - 密语/暗号 → 只有共享暗号的人才能理解含义

3. **「没说的话」特别重要**：古风 NPC 说话含蓄，很多信息不是用来说的，是靠暗示的。但感知隔离规则要求：
   - NPC 可以在对话中**暗示自己知道某事**（通过隐晦的表达）
   - 但 NPC 不能暗示自己**不可能知道**的事
   - 如果林雪不在场时发生的事，沈明月可以用模糊的语言试探，不能具体引用

4. **战乱/夜间的信息盲区**：古风模板中，以下场景默认「信息阻断」：
   - 下雨/暴风夜 → 看不到远处，听不到外面
   - 庭院深处 → 外面的侍从听不到
   - 战时/警戒状态 → 信息传递受阻，信使可能被截
