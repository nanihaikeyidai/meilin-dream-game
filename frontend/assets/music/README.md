# 背景音乐

## 开始菜单（全剧本共用）

```
music/menu/bgm.mp3    ← Sweet Route Echo，游戏内标题/开始界面循环播放
```

## 对局内（按剧本）

```
music/
  changan-moon/       月下长安 — bgm_1.mp3, bgm_2.mp3（交替）
  campus-summer/      夏日的回音 — bgm_1.mp3, bgm_2.mp3（交替）
  cafe-night/         深夜咖啡店 — bgm_1.mp3, bgm_2.mp3（交替）
  suspense-mansion/   镜像之馆 — bgm_1.mp3（单曲循环）
```

路径在 `template-registry.js` 的 `bgmTracks` 中配置；进入游戏主界面后自动播放。
